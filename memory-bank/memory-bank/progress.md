# VideoFeedback — Progress

> История разработки. Обновляй после завершения каждой фичи.

## Статус проекта

**Фаза:** MVP задеплоен, идут холодные продажи + итерации по обратной связи
**Хостинг:** Railway (Next.js + PostgreSQL + Redis)
**Биллинг:** Ручные переводы, admin-панель для переключения тарифов
**Продажи:** Холодные сообщения агентствам напрямую
